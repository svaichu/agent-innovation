# Glossary

| Term | Meaning |
|---|---|
| ARR | Annual recurring revenue from Canopy subscriptions. |
| Canopy | Our cloud dashboard and API. |
| CO2 | Carbon dioxide, measured in parts per million (ppm); a proxy for ventilation. |
| PM2.5 | Fine particles smaller than 2.5 micrometres. |
| VOC | Volatile organic compounds. |
| LoRaWAN | Long-range, low-power radio network used by our sensors. |
| Gateway | Device that forwards sensor radio messages to the cloud. |
| OTA | Over-the-air firmware update. |
| RMA | Return merchandise authorisation: the number and process for returned devices. |
| Churn | Subscription revenue lost through cancellation or downgrade. |
| SEV1 to SEV3 | Incident severity levels; SEV1 is the most severe. |
| SLA | Service level agreement. |
