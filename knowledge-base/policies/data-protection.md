# Data protection and classification

Data Protection Officer: Jolanda Esposito (E113). Coordination with Finance and Administration: Miriam Scholz (E23).

## Classification
| Level | Meaning | Examples |
|---|---|---|
| public | May be shared outside | Help articles, data sheets |
| internal | All staff | Processes, directory, systems |
| confidential | Named roles only | Strategy, customer contracts, personnel data, key accounts |

Every page in this knowledge base carries its level in the front matter. Tools that read the knowledge base must respect it: an employee sees only what their role allows.

## Rules
- Collect only data needed for a stated purpose.
- Data subject requests go to E113 on the day received; the deadline is one month.
- Customer data is deleted 90 days after a contract ends.
- Processors need a data processing agreement before use.
- A **data protection impact assessment** is required before any new processing of personal data at scale, and before any profiling of individuals.
- Personnel and candidate data may be used only for the purpose it was collected for. It is never used to train or evaluate a model.
