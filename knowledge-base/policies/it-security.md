# IT security

- Use the company password manager and multi-factor authentication everywhere.
- Laptops are encrypted and lock after 5 minutes.
- Install updates within 7 days; critical updates within 48 hours.
- No customer data on private devices or USB sticks.
- Access follows the role; it is reviewed every 6 months.
- Report lost devices and suspicious messages in #incidents within 1 hour.
