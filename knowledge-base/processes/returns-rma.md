# Returns and repairs (RMA)

**Process owner:** Ingrid Solberg (E20)

**Starts when:** support decides a device is probably faulty.

## Steps
1. E18 creates an RMA number in Zendesk and sends a return label.
2. E22 tests the device within 5 working days of arrival.
3. Under warranty: replace free of charge. Outside warranty: quote repair or replacement.
4. E22 records the fault code in the RMA spreadsheet.
5. E20 reviews fault codes monthly with E04.
